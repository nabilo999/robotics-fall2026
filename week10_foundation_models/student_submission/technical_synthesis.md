The biggest thing I noticed across all three missions was no matter how much info I gave the robot it could still be wrong. Giving the model more information sometimes helped, but it did not guarantee a better result.

In Mission 1, the model said the cup was empty even though it had no observation showing that. For the unclear request, it gave a vague answer instead of asking which object or location I meant. When I made my request more specific, it just repeated my instructions back to me. The wording was clearer, but the answer was not more useful. In Mission 2, the model called the drawing compass a tape measure. After I asked it to explain the visible features, it called it scissors and added details that were not supported by the picture. It did correctly place the black post to the right of the tool, so some claims matched the image while others did not. In Mission 3, none of the prompts reached the target. My decision-table prompt still produced repeated UP moves and ended at (1,2), with 15 blocked moves. 
Overall, I learned to compare the model’s answer with the actual evidence and results instead of trusting how convincing it sounds.
